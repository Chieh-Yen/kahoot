# Quiz Live — 自架版 Kahoot

即時多人搶答遊戲。一個 Node.js 程式就能跑，不需要資料庫、不需要網路上的 CDN（區網離線也能玩）。
實測單一筆電可同時支撐 300 位玩家（記憶體約 60 MB、廣播延遲 p95 < 25 ms）。

## 功能

- **題目編輯器** `/editor`：單選、複選、是非、填空、投票（不計分）；每題可設定秒數、標準/雙倍/不計分、圖片（上傳自動壓縮或貼網址）；排序、複製、刪除；JSON 匯入/匯出；CSV 批次匯入（附範本）；Ctrl/⌘+S 儲存。
- **主持人大螢幕** `/host`：選測驗 → 大廳顯示網址、PIN、QR Code、即時玩家名單（點名字可踢人）、鎖定房間 → 題目預覽 → 倒數作答（顯示已作答人數）→ 公布答案與分布圖 → 前五名排行榜（名次變動動畫）→ 最後一題後進入**頒獎典禮**（第五、四、三、二、一名依序揭曉，鼓聲、彩帶）→ 完整成績與題目分析，可下載 CSV / JSON。
- **玩家手機** `/`：輸入 PIN（或掃 QR）→ 取暱稱、選頭像 → 作答 → 每題立即顯示對錯、得分、連勝、目前名次與「落後誰幾分」→ 最終名次。
- **計分**：答對得 `基本分 × (1 − 作答秒數/時限 ÷ 2)`（標準 1000、雙倍 2000），連續答對每題再加 100（最多 +500）。同分時依答對題數、答對總耗時排序。所有計時、判分都在伺服器端，正確答案在公布前不會傳到任何裝置。
- **斷線重連**：玩家或主持人重新整理頁面、手機切換 App、網路短暫中斷，都會自動回到原本的遊戲與狀態（含已作答）。
- 其他：全部作答完自動結束倒數、自動播放模式、允許/禁止中途加入、隨機題目/選項順序、玩家手機是否顯示題目、人數上限、提前結束、合成音效與背景音樂（右下角可單獨關閉背景音樂或全部靜音）、全螢幕、鍵盤操作（空白鍵 = 下一步、F 全螢幕、M 靜音、B 背景音樂開關）、手機防休眠、主持人密碼。

## 在筆電上執行（推薦）

```bash
npm install
npm start            # 預設 port 3000
```

終端機會印出網址：

- 主持人：`http://localhost:3000/host`（接投影機）
- 玩家：大廳畫面上會顯示區網網址與 QR Code（例如 `http://192.168.1.104:3000`），玩家手機需與筆電在**同一個 Wi-Fi**。若偵測到多個網卡，點網址可切換。

> 提示：公司/學校 Wi-Fi 有時會隔離裝置（client isolation），手機連不到筆電。此時可改用手機熱點，或用下面的 Cloudflare Tunnel。
> macOS 第一次執行時若跳出防火牆詢問，請按「允許」。

### 讓網際網路上的人也能加入（免費）

不想部署的話，用 Cloudflare 的免費 quick tunnel 把筆電開放到網路上：

```bash
brew install cloudflared
HOST_PASSWORD=你的密碼 npm start
cloudflared tunnel --url http://localhost:3000
# 會得到 https://xxxx.trycloudflare.com，主持人用這個網址開 /host，QR Code 會自動使用它
```

## 部署到免費雲端（Render）

1. 把程式推到 GitHub（`data/quizzes/` 也一起 commit，部署時會帶上去）。
2. Render.com → **New → Blueprint** → 選這個 repo（會讀 `render.yaml`，區域預設新加坡）。
3. 建立時會要求填 `HOST_PASSWORD`（主持人與編輯器密碼）。沒設定的話主持功能會停用，避免任何人都能改你的題目。
4. 完成後網址類似 `https://quiz-live.onrender.com`；開 `/host` 主持，大廳的 QR Code 會自動使用這個網址。之後每次 push 會自動重新部署。

免費方案的限制，以及程式的對應方式：

| 限制 | 對應方式 |
|---|---|
| 重啟/重新部署/休眠後硬碟清空 | ① git 裡的 `data/quizzes/` 每次部署都會帶上；② 你在網頁上開過或存過的測驗會備份在瀏覽器（IndexedDB），伺服器少了時，打開主持人頁或編輯器會自動還原 |
| 閒置 15 分鐘休眠，喚醒約需 1 分鐘 | 開場前幾分鐘先打開 `/host`；主持人頁與編輯器開著時每 4 分鐘自動 ping，遊戲中不會休眠 |
| 0.1 CPU、512 MB 記憶體 | 實測 100 人一整場只用約 1 秒 CPU、55 MB 記憶體，見下方「上場前彩排」 |

> 在其他電腦或清除瀏覽器資料後，瀏覽器備份就不在了。重要的測驗請在編輯器「匯出 JSON」，或在本機編輯後 commit 進 `data/quizzes/`。

### 上場前彩排（強烈建議）

部署後在自己電腦執行，用 100 個機器人實際打一場線上遊戲：

```bash
node scripts/loadtest.js --url https://你的網址.onrender.com --password 你的密碼 --players 100 --polling 1 --all-answer 1
```

看到 `PASS ✓` 且延遲在可接受範圍就沒問題（機器人遊戲結束後會自動關閉）。

## 環境變數

| 變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 監聽 port | `3000` |
| `HOST_PASSWORD` | 主持人/編輯器密碼。公開部署時務必設定 | 無（任何人可進編輯器） |
| `PUBLIC_URL` | 強制大廳顯示的加入網址，例如 `https://quiz.example.com` | Render 上自動使用 `RENDER_EXTERNAL_URL` |
| `DATA_DIR` | 測驗與成績存放位置 | `./data` |

測驗存在 `data/quizzes/*.json`，每場遊戲的成績會自動存到 `data/results/`。

## CSV 匯入格式

`題型,題目,選項1,選項2,選項3,選項4,正確答案,秒數,計分`

- 題型：`單選` `複選` `是非` `填空` `投票`
- 正確答案：選項編號（從 1 開始），複選用 `|` 分隔如 `1|3`；是非題填 `O` / `X`；填空題填可接受答案如 `木星|Jupiter`
- 計分：`標準` `雙倍` `不計分`

在編輯器左側點「匯入 CSV」，或下載「CSV 範本」用 Excel / Google 試算表編輯。

## 開發與測試

```bash
npm test                                     # 遊戲引擎單元測試（計分、連勝、排名、計時、重連、踢人…）
npm start &
npm run loadtest -- --players 100            # 100 個機器人透過真實 socket 完整玩一場並驗證結果
node scripts/loadtest.js --players 300 --all-answer 1
```

架構：`server.js`（Express + Socket.IO）、`src/game.js`（遊戲狀態機與計分，伺服器為唯一事實來源，每次狀態改變推送完整快照給各端，因此重連只要重送快照）、`src/quiz.js`（題目驗證）、`src/store.js`（JSON 檔案儲存）、`public/`（原生 JS 前端，無 build step）。
